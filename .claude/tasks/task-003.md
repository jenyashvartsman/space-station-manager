# Task 003 — Database Schema & Connection

## Objective

Build the `libs/db` library: define all six Drizzle schemas (station, modules, crew_members, resources, missions, event_log), create the database connection, configure Drizzle Kit, and generate the initial migration. After this task the database can be created and queried via Drizzle.

## Context

- Read `.claude/docs/database.md` — full schema definitions, indexes, FK relationships
- Read `.claude/docs/architecture.md` — libs/db folder structure, `@space-station/db` alias

## Schema Requirements

Follow `database.md` exactly. Key rules:
- All PKs are `uuid` with `defaultRandom()`
- All FK columns reference parent PKs
- `status` columns use `text` with TypeScript enum type
- `jsonb` columns: `reward` in missions, `payload` in event_log
- Add the three indexes from `database.md`: resources, event_log, missions

```json

  "options": {

}
```
